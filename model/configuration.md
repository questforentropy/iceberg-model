# Configuration 0 — the canonical dials

The configuration layer holds the tunable parameter values. Changing a dial bumps the patch
version and re-sits the battery. Configurations are the freest layer: fork and experiment
(see `CONTRIBUTING.md`).

## Topology: the sprinkled 3-sphere (S³)

The canonical closed 3D fabric is **S³** — the dimensional-ladder continuation of the measured
S² instruments. Rationale: S³ is homogeneous *and* isotropic (a flat 3-torus has globally
preferred wrap axes, at odds with the no-preferred-frame doctrine), and conformally flat — on
the right side of the model's fakeability result (GR-20..22: geometry can lie, the grain
cannot). **T³ is the control build, not an assumption** — topology is a dial the ST rows test
(ST-5..7 are the queued distinguishers). No 4th dimension enters the model: S³ is defined
intrinsically; embedding coordinates are sprinkler scaffolding only and never appear in the
exchange graph.

## Grid: static sprinkle, fixed once

The sprinkle is laid down **once at genesis** from iterated hashes — a static grid with fixed
total compute. Expansion and warping are *emergent* (perceived, from uniform slowdown), never
a re-gridding. This is a standing doctrine, measured in DS-1..3: fineness cures dynamics,
randomness cures counting.

## Scale constants and seeds

Each lab declares its own toy units at the top of its file — grain counts, coupling dials,
genesis seeds. There is **no global fit to nature anywhere in configuration 0**: every number
is in toy units, chosen for measurement clarity, and stated in the lab that uses it. Fitting
the dials to the world we live in is deliberately future work (paper §1.4) — the present
claim is mechanism sufficiency, not empirical adequacy.
